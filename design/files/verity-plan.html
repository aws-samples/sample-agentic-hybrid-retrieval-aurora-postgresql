    Where Aurora shows up
    

      
READER ENDPOINT
Retrieval SELECTs fan out to replicas — storage-level replication keeps lag in the tens of milliseconds.

      
WRITER ENDPOINT
Casework transactions and the search index queue only. The retrieval path never writes.

      
OPTIMIZED READS
NVMe tiered cache carries HNSW once the index outgrows the buffer pool.

      
SURVIVABLE CACHE
Warm pages across failover — no cold HNSW after a promote.

      
PROXY · SERVERLESS v2
Agent tool fan-out pooled through RDS Proxy; ACUs track room-scale bursts.
