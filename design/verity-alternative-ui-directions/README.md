# Verity alternative UI directions

Five additional product directions:

1. Casefile — answer-first, proof-adjacent editorial memo.
2. Evidence canvas — graph-first investigation.
3. Query microscope — controls, ranked candidates, and explanation in one split view.
4. Replay theater — chronological run replay.
5. Benchmark matrix — retrieval quality comparison.

These are design explorations. Production implementation should keep the existing
API contracts and replace representative values with real backend responses.
