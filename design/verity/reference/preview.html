Fusion explanation

Rank arithmetic, not score soup.

Keep RRF, raw diagnostics, and rerank score visibly separate. This page is the “why hybrid ranking is sane” moment.

k = 60 text 2.0 vector 1.0 fuzzy 1.0
RRF formula
RRF(d) =
  2 / (60 + text_rank(d))
+ 1 / (60 + vector_rank(d))
+ 1 / (60 + fuzzy_rank(d))

absent arm => 0
raw FTS / cosine / trigram are diagnostics
rerank_score is stored separately

WITH lex AS (... GIN tsvector ...),
     vec AS (... HNSW ORDER BY embedding <=> :qv ...),
     fuz AS (... pg_trgm similarity ...)

SELECT evidence_id,
       COALESCE(2.0/(60+lex.r), 0)
     + COALESCE(1.0/(60+vec.r), 0)
     + COALESCE(1.0/(60+fuz.r), 0) AS rrf
FROM lex
FULL JOIN vec USING (evidence_id)
FULL JOIN fuz USING (evidence_id)
ORDER BY rrf DESC
LIMIT 24;
