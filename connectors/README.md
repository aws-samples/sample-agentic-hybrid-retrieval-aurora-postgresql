# Optional connectors

The core lab uses synthetic data. Connector scripts are optional stretch exercises.

Recommended stretch paths:

1. GitHub live ingestion into Aurora.
2. Slack federated search without long-term message indexing.
3. AppFlow/Glue export normalization from S3.
4. Jira/Confluence or Salesforce connector scaffolds for demo tenants.

Do not use real customer data or broad production chat/message data in a workshop environment without explicit approval.
