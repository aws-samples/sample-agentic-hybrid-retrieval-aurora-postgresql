# Session abstract

## Title

Build agentic hybrid retrieval with Amazon Aurora PostgreSQL

## Abstract

As applications evolve from RAG to agentic workflows, retrieval must support more than top-k semantic matches. In this session, use Aurora PostgreSQL as the core search and context engine for agentic hybrid retrieval. Implement PostgreSQL full-text search for lexical retrieval, pgvector semantic similarity, SQL and metadata filters, fuzzy matching, reciprocal rank fusion, model-based reranking, source attribution, and retrieval diagnostics. Then wire these capabilities into agent tools that decompose complex questions, gather targeted evidence, compare sources, explain ranking signals, and synthesize cited answers. Leave with working code, schema patterns, ranking templates, and techniques for trustworthy retrieval-heavy AI applications.
