# Build agentic hybrid retrieval with Amazon Aurora PostgreSQL (DAT410-R)

**Level: 400 – Expert**

What if your agent's most convincing answer rests on the wrong evidence? Build agentic hybrid retrieval with Aurora PostgreSQL across more than 500,000 product listings in three connected hands-on labs. Debug SQL combining full-text search, pg_trgm fuzzy matching, and pgvector semantic search under shared filters. Repair reciprocal rank fusion, inspect Amazon Bedrock reranking, and compare retrieval settings against judged queries. Then build a Strands agent, connect its retrieval tools through Amazon Bedrock AgentCore Gateway, and deploy it to AgentCore Runtime. Trace its searches to cited specifications and reviews, and test what happens when requirements change. Leave with reusable retrieval SQL and working agent code.
